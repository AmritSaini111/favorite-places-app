# My Favorite Places — Enhanced Final Project

This Android app is built with Kotlin, Jetpack Compose, Room, Navigation Compose, Coil, and DataStore.

## Features
- Splash screen with animation
- Add place
- View place list
- View place details
- Edit place
- Delete place with confirmation dialog
- Image picker from gallery
- Save image URI
- Save latitude and longitude
- Open place in maps
- Search by name or address
- Sort by date, name, or rating
- Filter favorites
- Favorite toggle
- Rating system (1 to 5)
- Dark mode toggle
- Snackbar feedback
- Empty state UI

## Important
The manifest uses `Theme.FavoritePlaces` based on `Theme.AppCompat.DayNight.NoActionBar`.
The real Material 3 styling is applied in Compose through `FavoritePlacesTheme()`.
